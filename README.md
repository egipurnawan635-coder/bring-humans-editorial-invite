## Key Features

1. **Warm Editorial Broadsheet Design**
   * Inspired by classical literary dispatches and printing broadsheets.
   * Palette featuring tactile paper canvas (`#FBF7F0`, `#F5EEE2`), deep carbon ink (`#191410`), vibrant terracotta (`#C2410C`, `#9A3412`), and warm amber accents (`#FEF3C7`, `#B45309`).
   * Original inline SVG editorial plate (*Plate II: The Union of Agentic Code & Software Bounties*) depicting drafting compasses, keystone logic nodes, and dawn horizon rays.
   * Completely self-contained in a single file with zero external fonts, scripts, CDNs, or third-party dependencies.

2. **Prominent Referral Pass Card**
   * Clear personal inviter attribution crediting `@egi-17`.
   * High-contrast monospace code display for `75pngn23`.
   * Prominent, fully qualified direct invitation URL [https://make.fun/r/75pngn23](https://make.fun/r/75pngn23).
   * Dominant, high-visibility primary Join CTA button with active press physics.

3. **Instant Bilingual Support (EN / ID)**
   * In-page zero-dependency language switcher between **English (EN)** and **Bahasa Indonesia (ID)**.
   * Smoothly translates headlines, kickers, lead paragraphs, card labels, action buttons, articles, social composers, and transparency notices.
   * Updates `lang` attributes, `aria-pressed` states, and live DOM nodes dynamically.

4. **Comprehensive Copy & Share Controls**
   * **Copy Code:** One-click copying of `75pngn23` with polite status toast feedback.
   * **Copy Link:** One-click copying of `https://make.fun/r/75pngn23`.
   * **Share Pass:** Native Web Share API integration (`navigator.share`) with graceful fallback to clipboard copying and handling for user cancellations (`AbortError`).
   * **Truthful Clipboard Handling:** Modern Clipboard API with programmatic `<textarea>` fallback and denial-notice messaging.
   * **Social Composer Links:** Pre-formatted quick-share links for WhatsApp, Telegram, and X (Twitter) pre-filled with courteous invitation copy and the referral link.

5. **Accessibility & Responsive Standards**
   * Mobile-first responsive grid; fully verified with zero horizontal overflow down to 320px viewport width.
   * High text-to-background contrast meeting WCAG AA standards (carbon ink on warm paper exceeds 7:1).
   * Semantic HTML structure (`<header>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`).
   * Dedicated keyboard skip link (`.skip-link`) and distinct `:focus-visible` interactive outlines.
   * Full `@media (prefers-reduced-motion: reduce)` support.

## Local Development & Preview

The page requires no build steps, bundlers, or package managers. Run a local HTTP server with Python:

```bash
# Start local development server from the repository root
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in any modern web browser to view the page.
